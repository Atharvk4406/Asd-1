You should use 3 separate prompts when you get your sensors tomorrow. Each prompt will generate documentation for one part of your project, while keeping the code consistent across Arduino, Python, and the frontend.

These prompts are designed for regular ChatGPT, including ChatGPT without login. They do not require Codex, agents, or specialized tools.

1. Prompt for Arduino C++ documentation

Use this after you know which sensors you will use.

Copy this prompt:

Act as an expert Arduino C++ developer and electronics instructor.

I am participating in a hardware hackathon and am a beginner in Arduino. Generate complete Arduino C++ documentation for my project using the following details.

Project: [PROJECT NAME]
Problem statement: [PROBLEM]
SDG: [SDG]
Arduino board: Arduino Uno
Available sensors: [SENSOR NAMES AND MODULE NUMBERS]
Required features: [FEATURES]
Available components: [BREADBOARD, JUMPER WIRES, RESISTORS, ETC.]

Create the documentation in the following order:

1. Explain the purpose of each sensor and the data it provides.
2. Give an exact pin-to-pin wiring table for every sensor, including VCC, GND, signal pins, voltage requirements, and communication protocols.
3. Explain the complete circuit and identify pin conflicts or electrical compatibility issues.
4. List the Arduino libraries required and explain how to install them.
5. Provide a separate minimal test sketch for each sensor.
6. Provide the complete integrated Arduino C++ sketch for the project.
7. Explain every important part of the code, including setup(), loop(), pinMode(), digitalRead(), analogRead(), sensor libraries, and Serial communication.
8. Implement the required sensor-reading logic, calculations, thresholds, and decision-making.
9. Make the Arduino send structured, consistent data to Python through USB serial communication.
10. Explain the serial data format and provide realistic example outputs.
11. Include error handling for invalid readings and sensor failures.
12. Explain how to upload the code, select the board and port, and test the sensors using Serial Monitor.
13. Provide troubleshooting steps for wiring errors, incorrect readings, missing libraries, and serial communication problems.

Requirements:
- Provide complete, compilable code, not pseudocode.
- Use only the components I actually have.
- Verify voltage compatibility and avoid unsafe wiring.
- Keep pin assignments consistent throughout the documentation.
- Explain everything for a beginner.
- Do not invent sensor readings or claim physical testing was performed.
- If module details are missing, ask me for the necessary information.

Finish with a checklist to verify that the Arduino hardware and code work before integrating Python.

4. The correct order to use these prompts

Follow this sequence to avoid integration problems.

Step	What you do	What you obtain

1	Enter your actual sensors and components in Prompt 1	Arduino wiring and C++ code
2	Test each sensor using Arduino Serial Monitor	Verified individual sensor readings
3	Paste the final Arduino code into Prompt 2	Python backend
4	Test the Python backend against actual serial data	Working serial-to-API integration
5	Paste the backend's API format into Prompt 3	HTML/CSS/JavaScript dashboard
6	Run all three components together	Complete hardware-software prototype
